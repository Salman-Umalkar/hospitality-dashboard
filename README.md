
# 📊 Hospitality Analytics Dashboard

## 🔹 Project Overview

This project is a **Hospitality Analytics Dashboard** built using **Excel, SQL, and Power BI**.
It focuses on analyzing hotel business performance by tracking key metrics such as revenue, bookings, occupancy rate, and customer behavior.

The dashboard helps stakeholders make **data-driven decisions** to improve business performance.

---

## 🔹 Problem Statement

The hospitality industry generates large volumes of booking and revenue data, but businesses often struggle to extract meaningful insights.

This project aims to:

* Convert raw data into actionable insights
* Track important KPIs
* Identify trends and patterns
* Support better decision-making

---

## 🔹 Business Objective

* Improve overall revenue performance
* Reduce booking cancellations
* Analyze customer booking behavior
* Optimize occupancy rates
* Identify top-performing hotels and cities

---

## 🔹 Tools & Technologies Used

* **Excel** → Data cleaning & dashboard creation
* **SQL** → Data extraction, transformation, KPI calculations
* **Power BI** → Interactive dashboards & data visualization

---

## 🔹 Dataset Description

The dataset includes:

* Hotel information
* Room category details
* Booking data
* Aggregated booking data
* Date-related information

---

## 🔹 Data Processing (SQL)

* Cleaned and transformed raw data
* Created new columns like week number and formatted date
* Performed joins between multiple tables
* Calculated KPIs such as revenue and bookings
* Used advanced SQL functions:

  * `LAG()` → Week-over-week revenue change
  * `DENSE_RANK()` → Ranking cities and hotels

---

## 🔹 Dashboard Explanation

### 📄 Power BI Dashboard

#### 🔸 Page 1 – Overview

* KPI Cards: Total Revenue, Bookings, Occupancy %, Cancellation %
* Weekday vs Weekend performance comparison
* Revenue by property
* Weekly trend analysis
* Occupancy distribution

👉 Provides a quick overview of overall business performance

---

#### 🔸 Page 2 – Detailed Analysis

* Revenue by city
* Revenue by room class
* Booking status analysis (Checked-out, Cancelled, No-show)
* Platform-wise revenue analysis
* Hotel-wise performance comparison

👉 Helps in deeper analysis and decision-making

---

### 📊 Excel Dashboard

* Built using Pivot Tables and Charts
* Interactive filtering using slicers
* Provides quick and simple analysis without Power BI

---

## 🔹 Key Insights

* Weekday bookings generate higher revenue than weekends
* Mumbai contributes the highest revenue
* Majority of bookings are successfully completed
* Some booking platforms contribute significantly more revenue
* Revenue shows fluctuations on a weekly basis
